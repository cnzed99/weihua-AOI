# 1. **概述**

本文制定毛刺检测V1.1设计原型，目的是使软件开发项目阶段清晰、要求明确、任务具体，使之规范化、系统化和工程化，包括ui界面修改、系统结构修改、系统功能模块修改、检测流程修改。

# 2. **系统结构修改**

为适应多相机多检测工位需求，需在同一软件配置多项检测制程，制程间些许检测同一产品需要汇总结果，些许检测不同产品独立汇算。组织结构设计如下：

![1728627013006](https://s2.loli.net/2024/10/11/e2XlJORUhuTICEH.png)

## 2.1. **涉及功能模块**

|              | **功能修改**                                     |
| ------------ | ------------------------------------------------------ |
| 新建工程     | 增加制程组设置（添加、删除）                           |
| 制程设置     | 增加制程设置窗口（增加、修改）                         |
| 检测算法     | 增加侧面毛刺检测算法（算法插件）                       |
| 算法参数     | 改为插件模式，增加接口，包含算法参数、检测类、算法调用 |
| 统计、显示   | 增加同一制程组汇总良率检测结果合并                     |
| 缺陷统计列表 | 增加同一制程组缺陷检测结果合并                         |
| 质量等级     | 修改为同一制程组共用                                   |
| 打标设置     | 不同制程可能使用同一打标模块，增加IP\端口号区分        |
| 运动控制     | 不同制程可能使用同一PLC，增加IP\端口号区分             |
| 回放         | 增加不同制程区分                                       |
| 存图         | 增加不同制程区分                                       |
| 操作记录     | 增加不同制程区分                                       |
| 报警日志     | 增加不同制程区分                                       |
| 运行日志     | 增加不同制程区分                                       |
| 数据库       | 增加不同制程区分                                       |
| 数据统计     | 增加不同制程区分                                       |
| 检测线程     | 增加不同制程区分                                       |
| 打开汇总     | 一个制程时按钮不显示                                   |
