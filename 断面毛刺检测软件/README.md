# 1、appConfig.json

```
{
  "APP": {
    "Config": {
      "hasMarkConfig": true,
      "hasFocusConfig": true,
      "IsDark": true
    }
  }
}
```

hasMarkConfig：控制打标模块是否存在，每个产品检测结束时执行相应函数；

hasFocusConfig：自动对焦功能、运动控制等功能块；

IsDark：颜色主题
